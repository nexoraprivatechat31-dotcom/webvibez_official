# Project Brain: Glossary & Terminology

## Core Terms

- **Bay Map**: The piecewise coordinate path (`x = +3.2` RIGHT bay, `x = -3.2` LEFT bay) governing 3D phone travel during scrolling.
- **Clean Phone Stage**: The design principle mandating pure, unobstructed whitespace around the 3D phone model without floating badges or satellite chips.
- **Focus Depth**: The cinematic CSS and 3D depth system that focuses the primary element (sharp, full opacity) while gently defocusing secondary side elements.
- **Hardware DRM**: Security architecture in mobile and web apps preventing screen recording, blacking out unauthorized captures, and overlaying dynamic user watermarks.
- **LibSQL / Turso**: The serverless edge database engine powering the WebVibez blog and article metadata storage.
- **Syndication Adapter**: A platform-specific module (e.g. `devto.ts`, `webflow.ts`, `notion.ts`) that transforms and distributes published articles to external developer and blogging networks.
- **Whitelabel**: 100% custom-branded client applications published under the client's own Google Play and Apple App Store developer accounts with full source code ownership.
